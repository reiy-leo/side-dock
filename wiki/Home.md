# Side Dock

A macOS multi-desktop (Spaces) tool: **the native Dock stays the same on every desktop, and what differs per desktop lives in a "side dock" pinned to the screen edge.**

Start from the sidebar: read [[Download and Install|Download-and-Install]] first, then the [[User Guide|User-Guide]].

Design notes, experiments and development conventions live in the repo's [docs/](https://github.com/reiy-leo/side-dock/tree/main/docs) and [AGENTS.md](https://github.com/reiy-leo/side-dock/blob/main/AGENTS.md).
