**English** | [[中文|使用指南]]

A Dock-shaped icon appears in the menu bar, titled with the current desktop number.

| Action | Result |
| --- | --- |
| **Click** | Switch to the next desktop (wraps). Can be changed to "Open menu" in Settings |
| **⇧-click** | Switch to the previous desktop (wraps). If click is set to "Open menu", this opens the menu too |
| **Right-click / ⌥-click** | Open the menu |

The menu: desktop list (current one checked, click to switch) → Next Desktop → Previous Desktop → Reset This Desktop from Current Dock → Refresh Desktops → Restore Original Dock Now → Debug Panel / Settings → **Quit and Restore Dock**.

> Can't see the icon? If "Automatically hide the menu bar" is on, move the pointer to the top of the screen. The app is an `LSUIElement`: no Dock icon and no main window.
