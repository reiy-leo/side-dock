[[English|Troubleshooting]] | **中文**

| 现象 | 先看这里 |
| --- | --- |
| 切了桌面，Dock 没变 | **默认的冻结模式下本来就这样**：原生 Dock 不变，各桌面的 App 看次级条。次级条没出来，就确认「显示次级 Dock 条」开着，而且这个桌面配了 App |
| 次级条不显示，或者不像以前那样动 | 先确认开关开着。在全屏 App 的空间里，它和原生 Dock 一样会藏起来；开了自动隐藏时，它跟原生 Dock 一起出现和隐藏 |
| 鼠标移上去不滑出 | 把鼠标移到 Dock 上沿露出来的那半条上。如果点击和悬停都没反应，记下来反馈（备选办法是提高窗口层级） |
| 某个位置选项是灰的 | 那条边被台前调度占着（选项后面标着「台前调度」），或者这个桌面的这条边已经放满 3 根栏 |
| 「立即应用」是灰的 | 默认 Dock 是空的，先点「从当前 Dock 抓取」 |
| 菜单栏里没有图标 | 可能开了自动隐藏菜单栏，把鼠标移到屏幕顶端 |
| 桌面名提示不弹 | 看 设置 → 通用 → 桌面切换 → 「切换桌面时显示桌面名称」开没开。刚启动的第一次，以及从全屏 App 退回桌面时，**故意不弹** |
| 启动后弹「已自动还原上次未还原的 Dock」 | 上次是被强杀或崩溃退出的，App 已经自动把 Dock 还原成基准。这是正常的 |
| 桌面功能用不了 | SkyLight 私有 API 失效了（一般在系统大版本升级后）。App 会降级成"只能手动改 Dock，不能自动跟随和切换"，调试面板里会写原因 |
| 别的情况 | 看 `~/Library/Application Support/MultiDock/multidock.log`，每次应用和还原都记了耗时和结果 |
