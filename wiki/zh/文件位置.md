所有文件都在 `~/Library/Application Support/MultiDock/`：

| 文件 | 用途 |
| --- | --- |
| `baseline.plist` | 第一次运行时整个 `com.apple.dock` 的只读备份，**以后不覆盖** |
| `config.json` | 桌面绑定和设置（原子写入） |
| `session.state` | 会话标记。正常退出时删掉，**还在就说明上次被强杀了** |
| `multidock.log` | 运行日志（最多 512 KB），反馈问题时直接附上 |
| `backups/` | 每次写 Dock 前的完整备份，留最近 20 份 |
| `sync-settings.json` | 同步设置（选的同步文件夹、自动同步开关），只在本机，不同步 |
| `device-id` | 读不到硬件 UUID 时才有：本机的同步 ID |

开了同步的话，云盘文件夹里还有一份 `SideDock/<硬件 UUID>.json`，见 [[设置：数据与同步|设置-数据]]。

如果登录启动用的是 LaunchAgent 兜底，还会有一份 `~/Library/LaunchAgents/local.multidock.loginitem.plist`。

**调试面板**（菜单栏 → 调试面板…）里能看到当前的 `spaceUUID` / `id64` / `type`、认到的桌面列表、实时日志，以及上面这些文件的路径。
