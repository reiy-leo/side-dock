```bash
swift build -c release --disable-sandbox   # 编译（--disable-sandbox 在本机是必须的，见下）
swift test --disable-sandbox               # 全部单元测试
./scripts/build-app.sh                     # 组装 build/Side Dock.app（ad-hoc 签名）
open "build/Side Dock.app"                 # 运行
```

一定要打包成 `.app` 再运行：直接跑 `.build/release/MultiDock` 没有 bundle，菜单栏图标和登录项都会出问题。

> **`--disable-sandbox` 不能省。** SwiftPM 自带的 `sandbox-exec` 在本机会报 `sandbox_apply: Operation not permitted`，
> manifest 编译直接失败，报错是 `error: 'multi-dock': Invalid manifest`。看起来像 `Package.swift` 坏了，其实是环境问题。

要登录时自动启动，到 **设置 → 通用 → 启动与自愈** 里打开开关（默认关）。

## 开发与验收

```bash
swift build -c release --disable-sandbox
swift test --disable-sandbox
```

**改了动 Dock 的代码，一定要跑真实验收**（会真的改 `com.apple.dock`，重启 Dock 几十次，跑完自动还原）：

```bash
defaults export com.apple.dock /tmp/dock-backup.plist     # 先手工备份一次
MULTIDOCK_DOCK_ACCEPTANCE=1 swift test --disable-sandbox --filter DockAcceptanceTests
```

跑的时候**别手动改 Dock**，不然会报假失败。

其他约定（`--disable-sandbox`、1Password 签名的 git 提交、构建零警告、文档同步）都写在 [AGENTS.md](https://github.com/reiy-leo/side-dock/blob/main/AGENTS.md) 里。
